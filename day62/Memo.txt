// 各層職責與邊界

╔═════╦═════════════╦══════════════════╗
║    層    ║           職責           ║             不該做的事             ║
╠═════╬═════════════╬══════════════════╣
║Controller║解析 HTTP 請求、回傳狀態碼║不含業務邏輯；不直接操作資料庫      ║
╠═════╬═════════════╬══════════════════╣
║Service   ║業務規則、呼叫 Repository ║不處理 HTTP 細節（狀態碼、Headers） ║
╠═════╬═════════════╬══════════════════╣
║Repository║資料庫 CRUD、查詢方法     ║不含業務邏輯                        ║
╠═════╬═════════════╬══════════════════╣
║Entity    ║資料結構定義、資料庫映射  ║不含 API 邏輯                       ║
╚═════╩═════════════╩══════════════════╝

<!-- Validation -->
<dependency>
	<groupId>org.springframework.boot</groupId>
	<artifactId>spring-boot-starter-validation</artifactId>
</dependency>

┌───────────────────────────────────────┐
│                                  Annotation                                  │
└───────────────────────────────────────┘

// @NotBlank
📖 概念 : 字串不能是 null、空字串或只有空白
┌────┬────────────┐
│  屬性  │         功能           │
├────┼────────────┤
│message │驗證失敗時顯示的錯誤訊息│
└────┴────────────┘
📝 範例	: @NotBlank(message = "書名不得為空")

------------------------------------------------------------------------------------

// @Size
📖 概念 : 限制字串、集合等資料的長度或數量
┌────┬─────────────┐
│  屬性  │           功能           │
├────┼─────────────┤
│max     │ 設定允許的最大長度       │
├────┼─────────────┤
│message │ 驗證失敗時顯示的錯誤訊息 │
└────┴─────────────┘
📝 範例	: @Size(max = 200, message = "書名長度不可超過 200")

------------------------------------------------------------------------------------

// @Pattern
📖 概念 : 檢查字串是否符合指定的格式
┌────┬──────────────┐
│  屬性  │            功能            │
├────┼──────────────┤
│regexp  │設定字串必須符合的正規表示式│
├────┼──────────────┤
│message │驗證失敗時顯示的錯誤訊息    │
└────┴──────────────┘
📝 範例	: @Pattern(regexp = "^[0-9-]{10,17}$", message = "ISBN 格式不正確")

------------------------------------------------------------------------------------

// @NotNull
📖 概念 : 資料不能是 null
┌────┬─────────────┐
│  屬性  │           功能           │
├────┼─────────────┤
│message │ 驗證失敗時顯示的錯誤訊息 │
└────┴─────────────┘
📝 範例	: @NotNull(message = "價格不得為空")

------------------------------------------------------------------------------------

// @Positive
📖 概念 : 數值必須大於 0
┌────┬─────────────┐
│  屬性  │           功能           │
├────┼─────────────┤
│message │ 驗證失敗時顯示的錯誤訊息 │
└────┴─────────────┘
📝 範例	: @Positive(message =  "價格必須大於 0")

------------------------------------------------------------------------------------

// @Min
📖 概念 : 數值不能小於指定的最小值
┌────┬─────────────┐
│  屬性  │           功能           │
├────┼─────────────┤
│value   │ 設定允許的最小數值       │
├────┼─────────────┤
│message │ 驗證失敗時顯示的錯誤訊息 │
└────┴─────────────┘
📝 範例	: @Min(value = 0, message = "庫存不可為負數")
