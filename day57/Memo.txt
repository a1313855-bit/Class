💡 我的理解 : 自動加入 Entity 的 Set and Get

pom.xml
-> Add Spring Boot Starters...
-> Developer Tools -> Lombok

使用 Lombok.jar 📝 範例 : lombok1.18.42.jar
-> .jar會自動搜尋 Eclipse 路徑
-> Install/Update

到 Eclipse 的資料夾中找到 eclipse.ini
-> 最下面會有一行你的 Eclipse 資料夾路徑\lombok.jar 📝 範例 : -javaagent:C:\eclipse\lombok.jar
-> 重新啟動 Eclipse 在 Entity class 上面加上 @Data
-> 註解 Get and Set -> 測試
