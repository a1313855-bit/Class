//================================== 一對多關聯 ==================================//

// @OneToMany
┌──────┬─────────┬─────────────────┐
│    屬性    │     簡單理解     │             這裡代表             │
├──────┼─────────┼─────────────────┤
│mappedBy    │關聯由誰管理      │Employee.department 管理          │
├──────┼─────────┼─────────────────┤
│cascade     │操作要不要連帶影響│儲存 Department 時也儲存 Employee │
├──────┼─────────┼─────────────────┤
│fetch       │對面是哪個類別    │對面是 Employee                   │
├──────┼─────────┼─────────────────┤
│targetEntity│關聯資料什麼時候查│Employee 需要時才查               │
└──────┴─────────┴─────────────────┘
📝 範例 :
@OneToMany(mappedBy = "department",
	cascade = CascadeType.PERSIST,
	targetEntity = Employee.class,
	fetch = FetchType.LAZY)

┌─────────────────────┬───────────────────────┐
│                Annotation                │                 可以先理解成                 │
├─────────────────────┼───────────────────────┤
│@JsonIgnore                               │這個屬性不要進 JSON                           │
├─────────────────────┼───────────────────────┤
│@JsonIgnoreProperties("employees")        │這個物件可以進 JSON，但忽略它裡面的 `employees│
├─────────────────────┼───────────────────────┤
│@JsonManagedReference + @JsonBackReference│雙向關聯只讓 JSON 往一個方向展開，避免無限循環│
└─────────────────────┴───────────────────────┘
